# DMD Beauty Salon - Website Project

Welcome to the official GitHub repository for the **DMD Beauty Salon** website. This project is a responsive, multi-page website designed to showcase salon services, pricing, salon details, and booking inquiries.

---

## 📌 Project Overview

DMD Beauty Salon provides beauty and grooming services including lash extensions, hair braiding, wig installations, professional makeup, and nail art. This website is built using standard HTML and CSS to deliver a clean layout across desktop, tablet, and mobile devices.

### Included Web Pages
* **`index.html`** – Home page with salon highlights and quick links.
* **`about.html`** – Salon story, mission, and team background.
* **`services.html`** – Service menu with pricing in ZAR (R) for lashes, braids, wigs, makeup, and nails.
* **`enquiry.html`** – Booking and service enquiry form.
* **`contact.html`** – Contact information, opening hours, and location details.

---

## 🛠️ Built With

* **HTML:** Semantic web elements used on every page for clear document structure.
* **CSS:** Built with a single external stylesheet (`style.css`). It includes CSS Grid, Flexbox, media queries for responsive design, and interactive pseudo-classes (`:hover`, `:focus`, `:active`).

---

## 🎨 Key Features

1. **Responsive Design:**
   * Media queries adapt the website layout for tablet and mobile screens.
   * Multi-column service layouts stack into single columns on smaller mobile viewports.
   * Images and typography resize fluidly to prevent horizontal scrollbars.

2. **Styling & Interaction:**
   * Styled color palette suited for a luxury beauty salon.
   * Visual feedback on buttons, links, and form fields using standard CSS pseudo-classes.
   * Clean navigation layout across all five pages.
