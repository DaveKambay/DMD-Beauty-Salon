# DMD Beauty Salon - Website Project

Welcome to the official GitHub repository for the **DMD Beauty Salon** website. This project is a fully responsive, multi-page web application featuring interactive JavaScript elements, form validation, SEO optimizations, and structured salon contact locations.

---

## 📌 Project Overview

DMD Beauty Salon provides professional beauty and grooming services including hair braiding, wig installations, professional makeup, and nail art. 

### Included Web Pages
* **`index.html`** – Home page featuring salon highlights, welcome banner, and quick navigation.
* **`about.html`** – Salon story, mission, and vision background.
* **`services.html`** – Service menu with pricing in ZAR (R) and an interactive image lightbox viewer.
* **`enquiry.html`** – Service booking enquiry form with client-side JavaScript validation and dynamic cost estimates.
* **`contact.html`** – Contact details, opening hours, dual physical locations (enhanced with location icons), and direct email message form.

---

## 🛠️ Built With

* **HTML5:** Semantic document structure utilized across all web pages.
* **CSS3:** External stylesheet (`style.css`) implementing Flexbox, CSS Grid, responsive media queries, and clean visual styling.
* **JavaScript (ES6):** Client-side form validation, dynamic price responses, mailto email compilation, and image lightbox modal effects.

## 🔄 Changelog

### Part 3 Updates:
* **JavaScript Integration (`script.js`):** Implemented robust client-side form validation for both `enquiry.html` and `contact.html`.
* **Interactive Lightbox:** Added a JavaScript modal feature allowing users to click on service images to view them in a larger lightbox display.
* **SEO Enhancements:** Incorporated optimized title tags, meta descriptions, and keywords across all pages, along with a `robots.txt` file and `sitemap.xml` for crawler optimization.
* **Form & Contact Improvements:** Configured enquiry submissions to display dynamic cost estimates, updated contact form behavior for email compilation, and added location icons (`📍`, `📞`, `🕒`) to the contact page layout.

### Part 2 Feedback Corrections & Edits:
* Refined CSS grid layout spacing and responsiveness across mobile and tablet viewports.
* Ensured consistent navigation header and footer styling across all 5 HTML pages.
* Corrected asset paths for service card images.
